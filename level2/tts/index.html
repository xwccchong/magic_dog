    TTS 语音合成¶

    概述¶

    TTS（Text-to-Speech）模块负责将 LLM 生成的文本回复转换为语音输出，在 Go2 机器狗上播放。系统采用 接口-连接器 架构，通过统一的 Speak 接口支持多种 TTS 后端可插拔切换。

    在系统中的位置¶

    L4 决策层 (LLM 推理)
    │
    ▼  输出文本回复
L3 技能层 (Speak Action)
    │
    ▼  调用 TTS 连接器
L2 内核层 (TTS 引擎)
    │
    ▼  合成音频 → 播放
L1 抽象层 (Go2 扬声器 / ALSA 声卡)

    Speak 接口¶

    所有 TTS 连接器都实现同一个 Speak 接口，定义在 src/actions/speak/interface.py：

    @dataclass
class SpeakInput:
    action: str          # LLM 生成的待朗读文本

@dataclass
class Speak(Interface[SpeakInput, SpeakInput]):
    input: SpeakInput
    output: SpeakInput

    接口极其简洁：输入一段文本，连接器完成语音合成与播放。

    架构设计¶

    Speak Action (L3)
    │
    ├── SpeakQwenTTSConnector      ← 阿里云 DashScope Qwen3-TTS (当前默认)
              │
              ▼
    Providers (单例)
    └── TTSPlaybackGateProvider ← 播放期间暂停 ASR 的协调门

    每个连接器由 Config（配置） + Connector（连接器） 两部分组成，通过 Pydantic Field 定义可配置参数，支持从 .env 和 JSON5 配置文件注入。

    TTS 后端¶

    1. Qwen TTS（当前默认）¶

    属性 值
    文件 src/actions/speak/connector/qwen_tts.py
    模型 qwen3-tts-flash
    音色 Cherry（可换）
    API https://dashscope.aliyuncs.com/api/v1/services/aigc/multimodal-generation/generation
    所需环境变量 DASHSCOPE_API_KEY

    两种播放模式：

    模式 说明
    stream 下载 WAV 后通过 ALSA 直接播放（aplay -D plughw:CARD=UACDemoV10），无需 Go2 DDS 通信
    wav 下载 WAV 后通过 Go2 AudioHub RPC 上传到机器狗扬声器播放

    调用流程：

    LLM 输出文本
  → SpeakQwenTTSConnector.connect()
    → _synthesize_to_wav() 调用 DashScope API
      → 返回 base64 编码的 WAV 数据或下载 URL
    → 写入临时 .wav 文件
    → _play_wav_on_go2() 通过 Unitree DDS RPC 上传到 AudioHub
      → MegaphoneEnter → MegaphoneUpload(分块) → 等待播放 → MegaphoneExit

    关键配置参数：

    参数 默认值 说明
    base_url https://dashscope.aliyuncs.com/api/v1 DashScope API 地址
    model_id qwen3-tts-flash 模型 ID，Flash 版延迟更低
    voice_id Cherry Qwen TTS 支持的音色
    language_type Auto 自动识别中英文
    playback_mode stream 播放方式
    silence_rate 0 无语音输入时跳过的 TTS 次数

    2. Kokoro TTS（本地）¶

    属性 值
    文件 src/actions/speak/connector/kokoro_tts.py
    模型 kokoro
    服务地址 http://127.0.0.1:8880/v1（本地部署）
    Provider KokoroTTSProvider → om1_speech.AudioOutputLiveStream

    Kokoro 是本地运行的 TTS 引擎，通过 OpenAI 兼容 API 调用（/audio/speech 端点）。音频通过 ffplay（SDL/ALSA）播放，不经过 Go2 扬声器。支持 TTS 打断（enable_tts_interrupt），当 ASR 检测到新语音输入时可中断正在播放的音频。

    KokoroTTSProvider 核心能力：

    • create_pending_message(text) — 创建待合成消息
    • add_pending_message(message) — 加入队列
    • clear_pending_messages() — 清空队列
    • register_tts_state_callback(callback) — 注册状态回调（如通知 ASR 暂停/恢复）

    通过 Zenoh 通信：

    Zenoh Topic                     方向        用途
robot/status/audio              Pub/Sub     音频状态（麦克风/扬声器）
om/tts/request                  Sub         接收 TTS 启停控制
om/tts/response                 Pub         返回 TTS 当前状态

    协调机制¶

    TTSPlaybackGateProvider¶

    定义在 src/providers/tts_playback_gate_provider.py，一个线程安全的单例门控：

    enter_playback()    → 标记 TTS 正在播放（ASR 暂停）
exit_playback()     → 标记 TTS 播放结束（ASR 恢复）
is_blocked()        → 查询当前是否应抑制 ASR

    silence_rate 机制¶

    避免机器人在没有对话时"自言自语"：当连续 N 个 tick 中没有语音输入（Voice: 字段）时，跳过 TTS 输出。仅在检测到用户语音后才恢复说话。

    对话历史存储¶

    每次 TTS 输出后，通过 TeleopsConversationProvider.store_robot_message() 记录机器人说的话到对话历史中（仅在当轮有 ASR 语音输入时记录）。

    默认配置¶

    当前 Go2 + Mid360 部署（无机械臂模式）使用 Qwen TTS 作为默认 TTS 后端：

    {
  name: "speak",
  llm_label: "speak",
  connector: "qwen_tts",
  config: {
    base_url: "https://dashscope.aliyuncs.com/api/v1",
    voice_id: "Cherry",
    model_id: "qwen3-tts-flash",
    language_type: "Auto",
    playback_mode: "stream",   // 或 "wav" (通过 Go2 扬声器)
  }
}

    调用路径总结¶

    用户说话 → ASR 识别 → LLM 推理
                         │
                    文本回复文本
                         │
immortals                  ▼
              ActionOrchestrator
                         │
              匹配 action="speak"
                         │
              SpeakXxxTTSConnector.connect()
                         │
          ┌──────────────———————————──┐
          ▼                           ▼             
      Qwen TTS                    Kokoro TTS    
    (DashScope)                   (本地 :8880)   
          │                           │              
          ▼                           ▼              
      合成 WAV                      合成音频      
          │                           │              
   ┌──────┴──────┐                    ▼              
   ▼             ▼                  ffplay       
 ALSA 直接   Go2 AudioHub  (外接扬声器)
 (aplay)     Megaphone RPC

    切换 TTS 后端¶

    在 JSON5 配置文件中修改 connector 字段即可切换：

    connector 后端 适用场景
    qwen_tts 阿里云 Qwen3-TTS 需要中文高质量语音，有网络
    kokoro_tts 本地 Kokoro 离线环境，外接扬声器
