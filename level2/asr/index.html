    语音识别 (ASR) 与唤醒词 (KWS) 模块详解¶

    模型路径：service/models/sherpa-onnx-kws-zipformer-wenetspeech-3.3M-2024-01-01/

    推理集成：src/inputs/plugins/qwen_realtime_asr.py → SherpaOnnxKeywordDetector

    本模块负责实时唤醒词检测（Keyword Spotting），在机器人语音交互中充当"耳朵"的触发器。当用户说出唤醒词（如"考拉"）后，系统才会将后续语音送入完整 ASR 流水线进行识别。

    文件详解¶

    1. ONNX 模型文件（6 个）¶

    文件 作用 精度
    encoder-...onnx 将音频特征编码为隐层表示 float32
    encoder-...int8.onnx 编码器 INT8 量化版，体积更小、推理更快 int8
    decoder-...onnx 从隐层表示解码为 token 序列 float32
    decoder-...int8.onnx 解码器 INT8 量化版 int8
    joiner-...onnx Transducer Joiner 网络，连接编码器与解码器 float32
    joiner-...int8.onnx Joiner INT8 量化版 int8

    命名规则解析：

    encoder-epoch-12-avg-2-chunk-16-left-64.onnx
        ↑          ↑      ↑          ↑
        │          │      │          └── 左侧上下文帧数: 64
        │          │      └── chunk 大小: 16 帧
        │          └── 最后 2 个 epoch 平均
        └── 训练第 12 个 epoch

    INT8 vs 全精度：本系统默认使用 encoder 和 joiner 用 INT8 量化版（速度快），decoder 用全精度版（保证精度）。

    2. tokens.txt¶

    定义了 228 个建模单元，主要包括：

    类型 示例 数量 说明
    特殊标记 <blk>, <sos/eos>, <unk> 3 空白符、起止符、未知符
    声母 (Initials) b, p, m, zh, ch, sh, j, q, x 等 ~27 拼音声母
    韵母 (Finals) ā, án, ǎng, ào, ēng, īng, ōng, ǔ 等 ~170 拼音韵母（带声调）
    特殊音素 #0 ~ #29 30 空白/噪音建模单元

    关键设计：建模单元带声调（ā/á/ǎ/à），这对中文唤醒词的精确识别至关重要。

    3. keywords.txt（唤醒词拼音序列）¶

    k ǎo l ā y ī h ào @考拉一号
k ǎo l ā @考拉

    格式：<拼音序列> @<中文唤醒词>

    每行定义一个唤醒词，空格分隔的拼音序列是模型实际匹配的内容。

    4. keywords_raw.txt（人类可读）¶

    考拉一号 @考拉一号
考拉 @考拉

    纯中文对照，用于参考和文档。

    工作原理¶

    KWS（Keyword Spotting）流程¶

    麦克风音频流 (16kHz, 16bit, mono)
        │
        ▼
┌─────────────────────────────┐
│    音频缓冲 (bytearray)      │
│    按帧切割: 0.1s = 3200 字节 │
└─────────────────────────────┘
        │
        ▼
┌─────────────────────────────┐
│    PCM → float32 归一化      │
│    int16 / 32768.0          │
└─────────────────────────────┘
        │
        ▼
┌─────────────────────────────┐
│  sherpa_onnx.KeywordSpotter │
│  ┌───────────────────────┐  │
│  │ create_stream()       │  │
│  │ accept_waveform()     │  │
│  │ is_ready() → 轮询     │  │
│  │ decode_stream()       │  │
│  │ get_result()          │  │
│  │ reset_stream()        │  │
│  └───────────────────────┘  │
└─────────────────────────────┘
        │
        ▼
   检测到唤醒词? 
     │
     ├── No  → 继续监听
     │
     └── Yes → 触发 ASR 流水线
               → 开始转录后续语音
               → 在 listen_window 内收集语音
               → 发送到 Qwen 实时 ASR 服务

    定义位置：src/inputs/plugins/qwen_realtime_asr.py 第 320-408 行

    """Adapter around sherpa-onnx KWS that accepts 16-bit mono PCM bytes."""

    def __init__(self, config: QwenRealtimeASRSensorConfig):

    初始化步骤：

    1. 校验模型路径：检查 tokens、encoder、decoder、joiner、keywords_file 五个文件路径是否配置且存在
    2. 创建 KeywordSpotter：使用 sherpa_onnx.KeywordSpotter(...) 初始化
    3. 创建解码流：self._spotter.create_stream()
    4. 计算帧大小：frame_bytes = sample_rate × frame_seconds × 2（16bit 单声道 = 2 字节/采样点）

    核心方法¶

    process_pcm(pcm: bytes) → bool¶

    def process_pcm(self, pcm: bytes) -> bool:
    # 1. 追加 PCM 数据到缓冲区
    self._buffer.extend(pcm)

    # 2. 按帧切割（每帧 0.1s = 1600 采样点 = 3200 字节）
    while len(self._buffer) >= self._frame_bytes:
        frame = self._buffer[: self._frame_bytes]
        del self._buffer[: self._frame_bytes]

        # 3. int16 → float32 归一化到 [-1.0, 1.0]
        samples = np.frombuffer(frame, dtype=np.int16).astype(np.float32) / 32768.0

        # 4. 送入解码流
        self._stream.accept_waveform(self.sample_rate, samples)

        # 5. 消费所有就绪的帧
        while self._spotter.is_ready(self._stream):
            self._spotter.decode_stream(self._stream)

        # 6. 检查检测结果
        result_text = self._result_text(self._spotter.get_result(self._stream))
        if result_text:
            logging.info("Sherpa-ONNX keyword detected: %s", ...)
            self._spotter.reset_stream(self._stream)  # 重置流
            return True

    return False

    关键设计点： - 流式处理：逐帧送入，支持无限长音频 - 非阻塞轮询：is_ready() + decode_stream() 组合，不阻塞主线程 - 检测后重置：检测到唤醒词后立即 reset_stream()，避免重复触发

    配置参数详解¶

    在 JSON5 配置文件中的完整配置：

    // wake word 基础开关
wake_word_enabled: true,                     // 是否启用唤醒词检测
wake_word_provider: "sherpa_onnx",          // 唤醒词引擎: sherpa_onnx | porcupine | openwakeword
wake_word_keywords: [                        // 内置唤醒词列表
  "koala_yi_hao", "koala"
],
wake_word_strip_prefixes: [                  // 去除的唤醒词前缀（兼容其他引擎）
  "hey", "ok"
],

// sherpa-onnx 模型文件路径（支持环境变量覆盖）
wake_word_sherpa_onnx_encoder: "${SHERPA_ONNX_KWS_ENCODER:-.../encoder-epoch-12-avg-2-chunk-16-left-64.int8.onnx}",
wake_word_sherpa_onnx_decoder: "${SHERPA_ONNX_KWS_DECODER:-.../decoder-epoch-12-avg-2-chunk-16-left-64.onnx}",
wake_word_sherpa_onnx_joiner:  "${SHERPA_ONNX_KWS_JOINER:-.../joiner-epoch-12-avg-2-chunk-16-left-64.int8.onnx}",
wake_word_sherpa_onnx_tokens: "${SHERPA_ONNX_KWS_TOKENS:-.../tokens.txt}",
wake_word_sherpa_onnx_keywords_file: "${SHERPA_ONNX_KWS_KEYWORDS_FILE:-.../keywords.txt}",

// 运行时参数
wake_word_sherpa_onnx_num_threads: 2,        // CPU 线程数
wake_word_sherpa_onnx_provider: "cpu",       // 推理后端: cpu | cuda | coreml
wake_word_sherpa_onnx_device: 0,             // 设备编号（多 GPU 时用）

// 音频参数
wake_word_sherpa_onnx_sample_rate: 16000,    // 采样率 (Hz)
wake_word_sherpa_onnx_feature_dim: 80,       // 特征维度（梅尔滤波器组数）
wake_word_sherpa_onnx_frame_seconds: 0.1,    // 每帧时长 (s)

// 解码参数
wake_word_sherpa_onnx_max_active_paths: 4,   // 最大活跃解码路径数
wake_word_sherpa_onnx_keywords_score: 1.5,   // 唤醒词偏置分数
wake_word_sherpa_onnx_keywords_threshold: 0.25,  // 检测阈值
wake_word_sherpa_onnx_num_trailing_blanks: 1,    // 尾随空白帧数

// ASR 监听窗口
wake_listen_window_seconds: 6.0,             // 唤醒后监听时长
wake_preroll_seconds: 2.0,                   // 唤醒词前保留的音频 (s)
wake_extend_on_speech_seconds: 2.0,         // 检测到语音时延长窗口 (s)

    关键参数调优指南¶

    参数 推荐范围 说明
    keywords_score 1.0 ~ 2.5 增大 = 更偏向匹配唤醒词（提高召回，可能增加误触发）
    减小 = 更严格（减少误触发，可能漏检）
    keywords_threshold 0.15 ~ 0.45 置信度阈值，只有分数超过此值才认为检测到
    增大 = 减少误触发
    减小 = 提高灵敏度
    max_active_paths 2 ~ 8 解码搜索宽度
    增大 = 更准确但更慢
    减小 = 更快但可能漏检
    num_threads 1 ~ 4 在 Jetson Orin 等边缘设备上建议 2

    唤醒词自定义¶

    添加新的唤醒词¶

    1. 编辑 keywords.txt，添加拼音序列：
    n ǐ h ǎo @你好
xiǎo d àn @小丹
    1. 同步更新 keywords_raw.txt（人类可读参考）：
    你好 @你好
小丹 @小丹
    1. 拼音序列规则：
    2. 空格分隔每个拼音单元（声母/韵母）
    3. 拼音单元必须来自 tokens.txt 中定义的集合
    4. 支持带声调的韵母（ā/á/ǎ/à）
    5. @ 后写中文对照

    拼音单元速查¶

    声母（部分） 韵母（部分）
    b, p, m, f ā, á, ǎ, à
    d, t, n, l ān, án, ǎn, àn
    g, k, h āng, áng, ǎng, àng
    j, q, x ōng, óng, ǒng, òng
    zh, ch, sh, r ī, í, ǐ, ì
    z, c, s ēng, éng, ěng, èng
    y, w ū, ú, ǔ, ù

    提示：完整的拼音单元列表请参看 tokens.txt，共约 200 个带声调的韵母。

    调试唤醒词¶

    启用分数日志来调优：

    wake_word_log_scores: true,
wake_word_score_log_interval_seconds: 5.0,

    日志会输出每次检测的置信度分数，用于确定合适的 keywords_threshold 值。

    唤醒词检测器的创建¶

    def _create_wake_word_detector(self):
    if not self.config.wake_word_enabled:
        return None

    provider = self.config.wake_word_provider
    if provider == "sherpa_onnx":
        return SherpaOnnxKeywordDetector(self.config)
    elif provider == "porcupine":
        return PorcupineWakeWordDetector(self.config)
    elif provider == "openwakeword":
        return OpenWakeWordDetector(self.config)
    else:
        raise ValueError(f"Unknown wake word provider: {provider}")

    系统支持三种唤醒词引擎，sherpa-onnx 是首选，因为： - 完全本地运行，无网络依赖 - 模型小（3.3M），CPU 即可实时推理 - 支持自定义唤醒词，不限于厂商预设
