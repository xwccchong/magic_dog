    manager.py 文件详解¶

    文件路径：/home/nvidia/MAGIC/src/runtime/manager.py

    这个文件实现了模式管理器（ModeManager），负责管理多模式系统的状态转换、生命周期钩子执行、LLM 路由决策等核心功能。

    数据类¶

    ModeState¶

    定义位置：第 48-74 行

    作用：存储模式系统的当前状态。

    @dataclass
class ModeState:
    current_mode: str                          # 当前模式
    previous_mode: Optional[str] = None        # 前一个模式
    mode_start_time: float = field(default_factory=time.time)  # 模式开始时间
    transition_history: List[str] = field(default_factory=list) # 转换历史
    last_transition_time: float = 0.0          # 最后转换时间
    user_context: Dict = field(default_factory=dict)  # 用户上下文

    字段说明：

    字段 类型 说明
    current_mode str 当前激活的模式名称
    previous_mode Optional[str] 转换前的模式名称
    mode_start_time float 当前模式激活的时间戳
    transition_history List[str] 模式转换历史记录
    last_transition_time float 最后一次转换的时间戳
    user_context Dict 用户上下文信息（用于上下文感知转换）

    check_time_based_transitions()

    │

    定义位置：第 502-607 行

    执行流程：

    _execute_transition("action", "input_triggered", "开始抓取")
        │
        ▼
    获取转换锁（防止并发转换）
        │
        ▼
    记录转换开始时间（用于冷却）
        │
        ▼
    构建转换上下文
    {
        "from_mode": "chat",
        "to_mode": "action",
        "reason": "input_triggered",
        "timestamp": 1705123456.789,
        "trigger_input": "开始抓取"
    }
        │
        ▼
    执行当前模式的 ON_EXIT 钩子
        │
        ▼
    执行全局 ON_EXIT 钩子
        │
        ▼
    更新状态：
    ├── previous_mode = "chat"
    ├── current_mode = "action"
    ├── mode_start_time = now
    ├── last_transition_time = now
    └── transition_history.append("chat->action:input_triggered")
        │
        ▼
    执行新模式的 ON_ENTRY 钩子
        │
        ▼
    执行全局 ON_ENTRY 钩子
        │
        ▼
    通知所有转换回调
        │
        ▼
    保存状态到文件
        │
        ▼
    释放锁，返回 True

    check_llm_router_transition(input_text)¶

    定义位置：第 707-778 行

    作用：使用 LLM 决定是否切换模式。

    流程：

    check_llm_router_transition("帮我拿瓶饮料")
        │
        ▼
    检查 mode_router.enabled 是否为 True
        │
        ▼

        "current_mode": "default",
        "available_modes": {...},

    主循环方法¶

    process_tick(input_text) 🔄¶

    定义位置：第 670-705 行

    作用：每个周期调用的主处理方法，检查所有可能的转换。

    执行顺序：

    async def process_tick(input_text: Optional[str]):
    # 1️⃣ 检查时间触发
    time_target = await check_time_based_transitions()
    if time_target:
        return (time_target, "time_based")

    # 2️⃣ 检查上下文感知
    context_target = await check_context_aware_transitions()
    if context_target:
        return (context_target, "context_aware")

    # 3️⃣ 检查输入触发
    if input_text:
        target_mode = check_input_triggered_transitions(input_text)
        if target_mode:
            return (target_mode, "input_triggered")

    # 4️⃣ 检查 LLM 路由
    router_target = await check_llm_router_transition(input_text)
    if router_target:
        return (router_target, "llm_router")

    return None

    优先级：时间 > 上下文 > 输入 > LLM 路由

    四种转换触发机制¶

    1. 时间触发 (TIME_BASED)¶

    {
    from_mode: "idle",
    to_mode: "default",
    transition_type: "time_based",
    timeout_seconds: 300  // 5分钟后自动切换
}

    2. 输入触发 (INPUT_TRIGGERED)¶

    {
    from_mode: "default",
    to_mode: "navigation",
    transition_type: "input_triggered",
    trigger_keywords: ["导航", "去", "移动到"],
    priority: 1
}

    3. 上下文感知 (CONTEXT_AWARE)¶

    {
    from_mode: "*",
    to_mode: "charging",
    transition_type: "context_aware",
    context_conditions: {
        "battery_level": {"min": 0, "max": 20}
    },
    priority: 10
}

    4. LLM 路由 (LLM_ROUTER)¶

    {
    mode_router: {
        enabled: true,
        min_confidence: 0.75,
        allowed_transitions: [
            {
                from_mode: "default",
                to_modes: ["chat", "action", "navigation"]
            }
        ]
    },
    mode_router_llm: {
        type: "OpenAILLM",
        config: {...}
    }
}

    设计要点¶

    要点 说明
    多触发机制 支持时间、上下文、输入、LLM 四种触发方式
    优先级控制 同类型规则按优先级执行
    冷却机制 防止频繁切换模式
    异步锁 防止并发转换冲突
    生命周期钩子 转换时自动执行进入/退出钩子
    状态持久化 重启后恢复上次的模式
    LLM 路由 智能决策模式切换
    长期记忆 结合历史上下文做决策
    Zenoh 通信 支持外部控制和监控
    回调机制 支持自定义转换回调

    使用示例¶

    初始化：¶

    from runtime.config import load_mode_config
from runtime.manager import ModeManager

    添加回调：¶

    def on_mode_change(from_mode, to_mode):
    print(f"Mode changed: {from_mode} -> {to_mode}")

manager.add_transition_callback(on_mode_change)

    处理周期：¶

    async def main_loop():
    while True:
        # 获取输入
        voice_input = get_voice_input()

        # 处理周期
        result = await manager.process_tick(voice_input)

        if result:
            target_mode, reason = result
            print(f"Transitioning to {target_mode} ({reason})")
            await manager._execute_transition(target_mode, reason)

        await asyncio.sleep(0.1)
