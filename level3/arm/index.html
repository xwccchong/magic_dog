    机械臂技能 (ARX X5 Arm Actions)¶

    文件路径：src/actions/arm_arx_x5_*/

    机械臂相关动作的上层接口定义。每个技能由一个 interface.py（定义输入参数）和 connector/（实现硬件通信）组成。

    技能定义方式¶

    每个机械臂技能遵循统一的目录结构：

    src/actions/arm_arx_x5_<skill>/
├── interface.py      # ★ 上层接口：定义 LLM 可调用的参数结构
├── connector/         # 硬件通信实现（Zenoh / ROS 2）
└── utils/             # 可选：辅助工具（规划器、运动客户端）

    interface.py 包含三个要素：

    # ① 动作类型枚举（如果技能有多种模式）
class ARXX5GraspAction(str, Enum):
    GRASP = "grasp"
    RESET = "reset"

# ② 输入参数 dataclass — LLM function-calling 的 schema 来源
@dataclass
class ARXX5GraspInput:
    action: ARXX5GraspAction
    target_name: str = ""
    top_k: int = 5

# ③ Interface 声明 — 注册到配置中
@dataclass
class ARXX5Grasp(Interface[ARXX5GraspInput, ARXX5GraspInput]):
    input: ARXX5GraspInput
    output: ARXX5GraspInput

    在 JSON5 配置中注册：

    agent_actions: [
  {
    name: "grasp_object",
    llm_label: "grasp_object",          // LLM function name
    connector: "arx_x5_grasp_zenoh",    // 使用哪个 Connector
    interface: "ARXX5Grasp",            // 指向 interface.py 中的 Interface 类
  }
]

    机械臂技能一览¶

    技能 llm_label 参数 说明
    grasp_object grasp_object action (grasp/put/reset/stop), target_name, strategy, top_k AnyGrasp 抓取：通过外部抓取服务生成抓取姿态
    yolograsp yolograsp action (grasp/reset), target_name, top_k, observation_index YOLO+中心点抓取：检测目标→计算深度→抓取
    hello hello action (run) 挥手动作序列 + 夹爪开合循环
    arm_x5_joint_nudge arm_x5_joint_nudge direction (left/right) 微调机械臂关节角度
    arm_x5_reset arm_x5_reset action: "reset" 机械臂回到初始位姿（复用 grasp_object 的 reset）
    gripper_count gripper_count action, count 夹爪重复开合指定次数

    详细参数¶

    grasp_object¶

    class ARXX5GraspAction(str, Enum):
    GRASP = "grasp"      # 抓取指定目标
    PUT = "put"          # 放置当前物体
    RESET = "reset"      # 机械臂归位
    STOP = "stop"        # 停止当前任务

class ARXX5GraspStrategy(str, Enum):
    ANYGRASP = "anygrasp"        # YOLO + AnyGrasp 完整管线
    YOLO_CENTER = "yolo_center"  # YOLO → 中心深度估算
    AUTO = "auto"                # 由执行器自动选择

@dataclass
class ARXX5GraspInput:
    action: ARXX5GraspAction           # 动作类型
    target_name: str = ""              # 目标描述，如 "red bottle"
    strategy: ARXX5GraspStrategy = ... # 感知策略
    top_k: int = 5                     # 抓取候选数量

    yolograsp¶

    class ARXX5YoloGraspAction(str, Enum):
    GRASP = "grasp"    # YOLO 检测 + 中心点抓取
    RESET = "reset"    # 机械臂归位

@dataclass
class ARXX5YoloGraspInput:
    action: ARXX5YoloGraspAction
    target_name: str = ""         # 目标名称
    top_k: int = 50               # YOLO 检测返回的最大数量
    observation_index: int = 1    # 观测视角索引（兼容多视角）

    hello¶

    class ARXX5HelloAction(str, Enum):
    RUN = "run"    # 执行挥手动作

@dataclass
class ARXX5HelloInput:
    action: ARXX5HelloAction = ARXX5HelloAction.RUN

    arm_x5_joint_nudge¶

    class ARXX5JointNudgeDirection(str, Enum):
    LEFT = "left"
    RIGHT = "right"

@dataclass
class ARXX5JointNudgeInput:
    direction: ARXX5JointNudgeDirection

    gripper_count¶

    class ARXX5GripperCountAction(str, Enum):
    REPEAT_GRIPPER = "repeat_gripper"

@dataclass
class ARXX5GripperCountInput:
    action: ARXX5GripperCountAction
    count: int                     # 开合次数

    从 LLM 输出到机械臂动作¶

    LLM 输出: Action(type="grasp_object", value='{"action":"grasp","target_name":"bottle"}')
    │
    ▼
ActionOrchestrator._promise_action():
    ├── parse value → {"action": "grasp", "target_name": "bottle"}
    ├── 匹配 interface = ARXX5Grasp
    ├── 类型转换: "grasp" → ARXX5GraspAction.GRASP
    ├── 构造 ARXX5GraspInput(action=GRASP, target_name="bottle", top_k=5)
    └── connector.connect(ARXX5GraspInput)
          └── Zenoh publish "arx_x5/grasp/request"
                → 后台 ARXX5GraspExecutor 收到
                → YoloSDK.detect() + GraspSDK.best_grasp()
                → 机械臂执行抓取
