    导航技能 (Navigate Actions)¶

    文件路径：src/actions/navigate_location/、src/actions/move_go2_autonomy/

    导航相关动作的上层接口定义。

    技能定义方式¶

    与机械臂技能相同，导航技能遵循 interface.py + connector/ 的结构：

    src/actions/navigate_location/
├── interface.py         # ★ 上层接口
└── connector/
    ├── autonomy_mid360_nav.py    # Mid360 自主导航 Connector
    ├── unitree_go2_nav.py        # Go2 原生导航 Connector
    ├── unitree_g1_nav.py         # G1 人形导航 Connector
    └── unitree_native_slam_nav.py # 原生 SLAM 导航 Connector

    导航技能一览¶

    技能 llm_label 目录 参数 说明
    navigate_location navigate_location navigate_location/ action (目标位置名) 导航到指定命名位置
    move_go2_autonomy move_go2_autonomy move_go2_autonomy/ action, speed, mode Go2 自主移动（路径规划）

    详细参数¶

    navigate_location¶

    @dataclass
class NavigateLocationInput:
    """
    action: 必须是已保存的位置名称，如 "仓库"、"起点"、"吧台"
    不要包含 "go to"、"navigate to" 等短语
    """
    action: str

    LLM 调用示例： 

    {"type": "navigate_location", "value": "仓库"}
{"type": "navigate_location", "value": "起点"}

    Connector 根据配置选择不同的底层实现：

    Connector 适用场景 实现方式
    autonomy_mid360_nav Mid360 + FAST-LIO 自主导航 查 JSON 位置文件 → publish_goal.sh → ROS 2 /goal_point
    unitree_go2_nav Go2 原生导航 Unitree SDK simple_nav_v3 可执行文件
    unitree_native_slam_nav Go2 原生 SLAM 导航 调用 simple_nav_v3 + 重定位

    move_go2_autonomy¶

    @dataclass
class MoveGo2AutonomyInput:
    action: str      # 移动指令，如 "move forward", "turn left"
    speed: float     # 移动速度
    mode: int        # 移动模式

    位置文件¶

    导航目标的位置坐标存储在 JSON 文件中：

    service/unitree_native_slam/
├── company_001_locations.json                      # 旧版 (6 区域)
└── company_20260630_100336_autonomy_locations.json  # 新版 (10 区域)

    格式：

    {
  "起点": [[5.47, -2.07, -0.34, -0.007, 0.013, 0.687, 0.725]],
  "仓库": [[-1.28, 0.77, 0.44, -0.07, -0.08, 0.89, -0.43]],
  "吧台": [[7.23, -0.68, 1.51, 0.01, -0.01, 0.04, 0.99]],
  ...
}

    每个位置 → 位姿列表 [x, y, z, qx, qy, qz, qw]，支持一个位置有多条备选位姿。

    从 LLM 输出到导航执行¶

    LLM 输出: Action(type="navigate_location", value="仓库")
    │
    ▼
ActionOrchestrator._promise_action():
    ├── parse value → {"action": "仓库"}
    ├── 匹配 interface = NavigateLocation
    ├── 类型转换: action="仓库"
    ├── 构造 NavigateLocationInput(action="仓库")
    └── connector.connect(NavigateLocationInput)
          │
          ├── lookup_pose("仓库") → [x,y,z,qx,qy,qz,qw]
          ├── bash publish_goal.sh <x> <y> <z> <qx> <qy> <qz> <qw>
          │     └── ROS 2 /goal_point 发布
          ├── FAR Planner 收到 → 规划路径
          └── Go2 开始导航 → 到达后 IOProvider 更新状态
