    Unitree Go2 SDK 安装¶

    官方网址:Go2 SDK 开发指南

    Github仓库:Github

    Unitree ROS2 Humble 安装¶

    配置不启动conda环境¶

    conda config --set auto_activate_base false

    jetson盒子系统环境¶

    • Ubuntu 22.04
    • ROS2 Humble
    • Unitree Go2
    • 机器人网段：192.168.123.161； mask：255.255.0.0

    获取当前设备的网卡与IP配置¶

    • IP配置 需要给jetson盒子连接显示器配置有线网络连接：在以太网处选择手动配置IP，输入IP与掩码（掩码需要和机器狗保持一致）。

      • 掩码：255.255.255.0
      • IP：192.168.123.xxx，可以自由配置，但是不能是 18、20、161结尾（这些是宇树机器狗自带jetson、雷达、本体的IP）

    • 查询网卡与IP

      终端输入指令：ifconfig

      示例输出：

      eno1: flags=4163<UP,BROADCAST,RUNNING,MULTICAST>  mtu 1500
    inet 192.168.123.103  netmask 255.255.255.0  broadcast 192.168.123.255
    inet6 fe80::4371:5e0e:a556:6520  prefixlen 64  scopeid 0x20<link>
    ether 48:b0:2d:fb:98:10  txqueuelen 1000  (以太网)
    RX packets 0  bytes 0 (0.0 B)
    RX errors 0  dropped 0  overruns 0  frame 0
    TX packets 63  bytes 7757 (7.7 KB)
    TX errors 0  dropped 0 overruns 0  carrier 0  collisions 0
    device interrupt 255  base 0x1000
      • 当前电脑网卡：eno1
      • 当前电脑 IP：192.168.123.103

    Unitree ROS2 安装¶

    参考网址为：unitreerobotics/unitree_ros2

    1. 克隆 Unitree ROS2 仓库¶

    cd ~
git clone https://github.com/unitreerobotics/unitree_ros2.git

    2. 安装依赖¶

    sudo apt update

sudo apt install ros-humble-rmw-cyclonedds-cpp
sudo apt install ros-humble-rosidl-generator-dds-idl

sudo apt install libyaml-cpp-dev
sudo apt install python3-colcon-common-extensions

sudo apt install \
    python3-empy \
    python3-catkin-pkg \
    python3-lark \
    python3-numpy

    3. 退出 Conda 环境¶

    ROS2 编译不要使用 Conda Python。

    如果终端前面显示：

    (base)

    退出：

    conda deactivate

    检查：

    which python3

    应该输出：

    /usr/bin/python3

    如果仍自动进入 base：

    conda config --set auto_activate_base false

    4. 编译 Unitree ROS2 Msg¶

    source /opt/ros/humble/setup.bash
cd ~/unitree_ros2/cyclonedds_ws
colcon build

    编译成功后应该出现文件夹：

    ~/unitree_ros2/cyclonedds_ws/install

    5. 修改 setup.sh¶

    主要是这个部分

    编辑：

    gedit ~/unitree_ros2/setup.sh

    修改内容：

    #!/bin/bash
echo "Setup unitree ros2 environment"

source /opt/ros/humble/setup.bash
source $HOME/unitree_ros2/cyclonedds_ws/install/setup.bash

export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp
export ROS_DOMAIN_ID=0

export CYCLONEDDS_URI='<CycloneDDS><Domain><General><Interfaces>
    <NetworkInterface name="enP8p1s0" priority="default" multicast="default" />
</Interfaces></General></Domain></CycloneDDS>'

    注意：

    eno1

    必须替换成实际连接机器狗的网卡名称。

    6. 加载环境¶

    source ~/unitree_ros2/setup.sh

    检查：

    echo $RMW_IMPLEMENTATION
echo $ROS_DOMAIN_ID
echo $CYCLONEDDS_URI

    应该看到：

    rmw_cyclonedds_cpp
0
...
eno1
...

    7. 测试 ROS2 通信¶

    重启 ROS2 daemon：

    ros2 daemon stop
ros2 daemon start

    查看 Topic：

    ros2 topic list

    正常情况下应该能看到：

    /lowstate
/lf/lowstate
/sportmodestate
/lf/sportmodestate
/wirelesscontroller
...

    测试订阅：

    ros2 topic echo /sportmodestate

    或：

    ros2 topic echo /lowstate

    8. 编译官方示例¶

    source ~/unitree_ros2/setup.sh

cd ~/unitree_ros2/example

colcon build

    9. 运行示例¶

    读取高层状态：

    ./install/unitree_ros2_example/bin/read_motion_state

    读取低层状态：

    ./install/unitree_ros2_example/bin/read_low_state

    使用自定义配置（网口 eno1）¶

    export CYCLONEDDS_URI=file:///home/nvidia/cyclonedds_ws/cyclonedds.xml

    • 需要修改这个文件中与机器狗本体通信的网口号

    GeekMind 环境配置¶

    参考/home/nvidia/web/docs/introduction/readme.md

    # Python 包编译时需要找到头文件和库
export CYCLONEDDS_HOME=/home/nvidia/cyclonedds/install
export CMAKE_PREFIX_PATH=/home/nvidia/cyclonedds/install


# 运行时加载动态库
export LD_LIBRARY_PATH=/home/nvidia/cyclonedds/install/lib:$LD_LIBRARY_PATH

# ROS 2 选择使用 CycloneDDS 作为 RMW
export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp

# 使用自定义配置（网口 eno1）
export CYCLONEDDS_URI=file:///home/nvidia/cyclonedds_ws/cyclonedds.xml

    现在的结构是三层架构：

    1. Python 层：cyclonedds==0.10.2（Python 绑定）
    2. ROS 2 层：rmw_cyclonedds_cpp（ROS 中间件）
    3. 核心层：CycloneDDS 0.10.5（DDS 通信库 + 自定义配置）
