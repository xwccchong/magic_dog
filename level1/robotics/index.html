    robotics.py 文件详解¶

    文件路径：/home/nvidia/MAGIC/src/runtime/robotics.py

    这个文件负责初始化 Unitree 机器人的网络通信通道，建立与机器人的以太网连接。

    目录¶

    • load_unitree 函数
    • 执行流程
    • 在 config.py 中的使用
    • 相关依赖

    load_unitree 函数¶

    定义位置：第 4-40 行

    作用：初始化 Unitree 机器人的网络通信通道。

    函数签名¶

    def load_unitree(unitree_ethernet: Optional[str]) -> None:

    参数¶

    参数 类型 说明
    unitree_ethernet Optional[str] 以太网适配器名称，如 "eth0"

    返回值¶

    • None

    功能说明¶

    该函数负责：

    1. 检查配置：判断是否提供了以太网适配器名称
    2. 初始化通道：调用 Unitree SDK 初始化网络通信
    3. 日志记录：记录初始化状态和错误信息

    执行流程¶

    流程图¶

    load_unitree(unitree_ethernet)
        │
        ▼
    unitree_ethernet 是否提供?
     │
     ├── No → 记录日志: "No robot hardware ethernet port provided."
     │         返回（不初始化）
     │
     └── Yes ↓
            │
            ▼
        记录日志: "Using {unitree_ethernet} as the Unitree Network Ethernet Adapter"
            │
            ▼
        导入 Unitree SDK
        from unitree.unitree_sdk2py.core.channel import ChannelFactoryInitialize
            │
            ▼
        调用 ChannelFactoryInitialize(0, unitree_ethernet)
            │
            ├── 成功 → 记录日志: "Booting Unitree and CycloneDDS"
            │
            └── 失败 → 记录错误日志
                       （注意：不抛出异常，仅记录）

    代码详解¶

    def load_unitree(unitree_ethernet: Optional[str]):
    # 1️⃣ 检查是否提供了以太网适配器
    if unitree_ethernet:
        logging.info(f"Using {unitree_ethernet} as the Unitree Network Ethernet Adapter")

        # 2️⃣ 导入 Unitree SDK（延迟导入，避免未安装时报错）
        from unitree.unitree_sdk2py.core.channel import ChannelFactoryInitialize

        try:
            # 3️⃣ 初始化网络通道
            # 参数 0 表示使用真实硬件模式
            ChannelFactoryInitialize(0, unitree_ethernet)
        except Exception as e:
            # 4️⃣ 错误处理：只记录日志，不抛出异常
            logging.error(f"Failed to initialize Unitree Ethernet channel: {e}")
            # raise e  # 注释掉了，不抛出异常

        logging.info("Booting Unitree and CycloneDDS")
    else:
        # 5️⃣ 未提供配置，跳过初始化
        logging.info("No robot hardware ethernet port provided.")

    参数说明¶

    unitree_ethernet 参数¶

    值 含义 场景
    "eth0" 使用 eth0 网卡 连接真实机器人
    "enp3s0" 使用 enp3s0 网卡 其他网卡名称
    None 或 "" 不初始化 纯软件模式/无机器人

    ChannelFactoryInitialize 参数¶

    ChannelFactoryInitialize(0, unitree_ethernet)
#                       ↑   ↑
#                       │   └── 以太网适配器名称
#                       └────── 模式：0=真实硬件，1=仿真模式

    在 config.py 中的使用¶

    from runtime.robotics import load_unitree

def load_mode_config(config_name: str, ...):
    # ...
    raw_config = json5.load(f)

    # 提取全局参数
    g_ut_eth = raw_config.get("unitree_ethernet")

    # 初始化 Unitree 机器人
    load_unitree(g_ut_eth)  # ← 在这里调用

    # 继续创建配置对象
    mode_system_config = ModeSystemConfig(
        unitree_ethernet=g_ut_eth,
        ...
    )

    错误处理策略¶

    当前实现：¶

    try:
    ChannelFactoryInitialize(0, unitree_ethernet)
except Exception as e:
    logging.error(f"Failed to initialize Unitree Ethernet channel: {e}")
    # raise e  # ← 注释掉了，不抛出异常

    特点： - 初始化失败时只记录日志，不抛出异常 - 允许系统在机器人网络不可用时继续启动 - 适用于开发/测试场景

    如果需要严格模式：¶

    try:
    ChannelFactoryInitialize(0, unitree_ethernet)
except Exception as e:
    logging.error(f"Failed to initialize Unitree Ethernet channel: {e}")
    raise e  # ← 取消注释，抛出异常

    相关依赖¶

    Unitree SDK¶

    from unitree.unitree_sdk2py.core.channel import ChannelFactoryInitialize

    这是 Unitree 官方提供的 Python SDK，用于与 Unitree 机器人通信。

    SDK 功能： - 网络通道初始化 - DDS（数据分发服务）通信 - 机器人状态订阅 - 机器人控制指令发布

    CycloneDDS¶

    日志中提到的 "CycloneDDS" 是底层的 DDS 中间件：

    Unitree SDK
    ↓
CycloneDDS（DDS 中间件）
    ↓
以太网通信
