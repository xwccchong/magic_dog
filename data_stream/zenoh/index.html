    Zenoh 通信中间件 (zenoh_msgs)¶

    文件路径：src/zenoh_msgs/

    以 Zenoh 为传输层、用 ROS 2 IDL 格式定义消息类型的通信库。

    本模块用 Zenoh 替代 ROS 2 的 DDS，作为机器人各模块之间的消息中间件。消息类型通过 pycdr2 定义，与 ROS 2 使用相同的 CDR 序列化格式，确保和 ROS 生态互通。

    会话管理 (session.py)¶

    def open_zenoh_session() -> zenoh.Session:
    # ① 先尝试 TCP 直连本机 zenohd
    local_config = create_zenoh_config(network_discovery=False)
    try:
        session = zenoh.open(local_config)
        return session
    except Exception:
        pass

    # ② 回退到网络自动发现
    config = create_zenoh_config()
    session = zenoh.open(config)
    return session

    连接策略：先 TCP 直连 127.0.0.1:7447，失败则 fallback 到网络组播自动发现。这样在本机有 zenohd 路由守护进程时走高效直连，没有时也能在局域网内自组网。

    Zenoh 是什么¶

    Zenoh（Eclipse 开源项目）是一个为边缘/机器人场景设计的 发布/订阅 + 查询 中间件，可视为 ROS 2 默认 DDS 的替代方案。

    DDS (ROS 2 默认) Zenoh
    发现机制 组播 (multicast)，大型网络下容易风暴 支持 peer-to-peer + 中心路由
    跨网段 配置复杂 天然支持，TCP 直连即可
    传输层 UDP 为主 TCP / UDP / 串口 均可
    跨语言 C++ / Python（需 IDL 生成代码） 原生多语言 SDK，无需代码生成
    适用场景 单机器人内部通信 多机器人 / 云边通信 / 弱网环境

    关键代码¶

    class ARXX5GraspZenohConnector(ActionConnector):
    def __init__(self, config):
        self.session = open_zenoh_session()        # ① 建连

    async def connect(self, output_interface):
        payload = {
            "action": output_interface.action.value,
            "target_name": output_interface.target_name.strip(),
            "strategy": output_interface.strategy.value,
            "top_k": top_k,
            "requested_at": time.time(),
        }
        self.session.put(                           # ② 发布
            "arx_x5/grasp/request",                #    topic
            ZBytes(json.dumps(payload))            #    payload
        )

    def stop(self):
        self.session.close()                        # ③ 释放

    为什么这样设计¶

    这是一个 大脑与身体分离 的架构模式：

    层 角色 通信方式
    大脑层 (LLM Agent) 决策：看到什么 → 该做什么 通过 Zenoh 发布请求
    身体层 (Executor) 执行：收到指令 → 操控硬件 通过 Zenoh 订阅请求

    核心收益：

    1. 解耦 — 大脑（Python/LLM）和身体（C++/ROS/硬件驱动）可以独立开发、部署在不同机器上
    2. 跨平台 — Zenoh 在 C++/Python/Rust 都有原生支持，比 DDS 更轻量
    3. 去 ROS 依赖 — zenoh_msgs/idl/ 用纯 Python dataclass 定义了和 ROS 2 等价的消息格式，不需要安装 ROS 就能理解机器人消息
    4. 调试友好 — Zenoh 可以用 tcp:// 直连，不需要复杂的 DDS domain 配置
